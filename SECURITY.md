# Security Policy

## Supported Versions

This is a single-page static site with no versioned releases - the `main`
branch is always the deployed, supported version.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, use GitHub's private reporting:

1. Go to the [Security tab](https://github.com/ArtuursG/METEO/security) of
   this repository.
2. Click **"Report a vulnerability"** to open a private advisory.

You should receive an initial response within a few days. If confirmed, a fix
will be prioritized and the advisory disclosed once resolved.
